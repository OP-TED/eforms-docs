= Withheld publication of information

[IMPORTANT]
====
From SDK 1.16, the information that may be withheld from publication, and the markup used to achieve this, has completely changed.

Summary of changes 

* Information to be withheld from publication is now arranged in 14 groups of similar Fields

* All Fields in an information group to be withheld from publication will be withheld

* Individual instances of Fields can no longer be withheld

* Some Fields can no longer be withheld from publication

* One group of Fields includes all information related to Tenderers

* There can be only one Justification Code, Justification Description and Disclosure Date per notice. These will apply to all withheld information in the notice

* The terminology used has changed 
====

Some information required by eForms may remain non-public
("undisclosed") for a defined periodfootnote:[as reminded in the "eForms Implementation Handbook" p. 27. Also see Dir 24 Art. 50(4), Dir 25 Art. 70(3),].
This feature may be used for Result, Contract Modification and Contract
Completion notices only.

For most undisclosed information groups, the non-disclosure feature is
available independently from the directive. The "Withheld award criteria"
group is exclusively accessible for the sectoral directive
(i.e. directive 25).

The reason for keeping the information private shall be specified using
a code from the codelist
https://op.europa.eu/web/eu-vocabularies/at-dataset/-/resource/dataset/non-publication-justification[non-publication-justification]
and optionally a description.

To activate the mechanism, four business terms have to be used:

* Undisclosed Information Group (BT-195)

* Non-disclosure Justification Code (BT-197)

* Non-disclosure Justification Description (BT-196)

* Disclosure Date (BT-198)

The information is encoded using dedicated elements:

[source,xml]
----
<efac:NoticeInformationNondisclosure>
    <!-- BT-198-notice -->
    <efbc:InformationDisclosureDate>2025-03-31+01:00</efbc:InformationDisclosureDate>
    <efac:NondisclosureJustification>
        <!-- BT-197-notice -->
        <cbc:NondisclosureJustificationCode listName="non-publication-justification">oth-int</cbc:NondisclosureJustificationCode>
        <!-- BT-196-notice -->
        <efbc:NondisclosureJustificationDescription languageID="ENG">Information delayed publication because of ...</efbc:NondisclosureJustificationDescription>
        <efbc:NondisclosureJustificationDescription languageID="FRA">Publication de l'information ajournée parce que ...</efbc:NondisclosureJustificationDescription>
    <efac:NondisclosureReference>
        <!-- BT-195-notice -->
        <efbc:NondisclosureID>cri-awrd</efbc:NondisclosureID>
    <efac:NondisclosureReference>
</efac:NoticeInformationNondisclosure>
----

The information to be withheld should use the extension mechanism at notice level (element ContractAwardNotice). This single structure replaces the implementation in previous versions of the SDK where unpublished information fields were located at the same level as the fields to be withheld.

The groups of fields to be withheld should be indicated using one or more codes from the codelist https://op.europa.eu/web/eu-vocabularies/at-dataset/-/resource/dataset/undisclosed-data-group[undisclosed-data-group] in the repeatable field Undisclosed Information Group (BT-195-notice).

[[withholdableGroupsSection]]
== Withholdable Groups

=== Withheld award criteria

This group is selected to be withheld using the code "cri-awrd". 

The use of this group is restricted to the sectoral directive only (i.e. directive 25).

* Award Criterion Type (BT-539-Lot)

* Award Criterion Description (BT-540-Lot)

* Award Criterion Weight Number (BT-541-Lot-WeightNumber)

* Award Criterion Fixed Number (BT-541-Lot-FixedNumber)

* Award Criterion Threshold Number (BT-541-Lot-ThresholdNumber)

* Award Criterion Number Weight (BT-5421-Lot)

* Award Criterion Number Fixed (BT-5422-Lot)

* Award Criterion Number Threshold (BT-5423-Lot)

* Award Criteria Complicated (BT-543-Lot)

* Award Criteria Order Justification (BT-733-Lot)

* Award Criterion Name (BT-734-Lot)




=== Withheld information about the framework agreement values

This group is selected to be withheld using the code "not-fram" 

* Notice Framework Maximum Value (BT-118-NoticeResult)

* Notice Framework Approximate Value (BT-1118-NoticeResult)

* Framework Maximum Value (BT-709-LotResult)

* Framework Re-estimated Value (BT-660-LotResult)




=== Withheld notice value

This group is selected to be withheld using the code "not-valu" 

* Notice Value (BT-161-NoticeResult)


=== Withheld value of the lowest and highest tender submitted

This group is selected to be withheld using the code "sub-lohi" 

* Tender Value Lowest (BT-710-LotResult)

* Tender Value Highest (BT-711-LotResult)


=== Withheld tender value

This group is selected to be withheld using the code "ten-valu" 

* Tender Value (BT-720-Tender)



=== Withheld concession estimates

This group is selected to be withheld using the code "con-esti" 

* Concession Revenue User (BT-162-Tender)

* Concession Revenue Buyer (BT-160-Tender)

* Concession Value Description (BT-163-Tender)




=== Withheld statistical information on received submissions

This group is selected to be withheld using the code "sub-stat" 

* Received Submissions Count (BT-759-LotResult)

* Received Submissions Type (BT-760-LotResult)





=== Withheld tender rank

This group is selected to be withheld using the code "ten-rank" 

* Tender Rank (BT-171-Tender)




=== Withheld tender variant

This group is selected to be withheld using the code "ten-vari" 

* Tender Variant (BT-193-Tender)




=== Withheld origin of product or service

This group is selected to be withheld using the code "ori-info" 

* Country Origin (BT-191-Tender)




=== Withheld subcontracting information

This group is selected to be withheld using the code "sub-info" 

* Subcontracting (BT-773-Tender)

* Subcontracting Value Known (BT-730-Tender)

* Subcontracting Value (BT-553-Tender)

* Subcontracting Percentage Known (BT-731-Tender)

* Subcontracting Percentage (BT-555-Tender)

* Subcontracting Description (BT-554-Tender)




=== Withheld review information

This group is selected to be withheld using the code "rev-info" 

* Buyer Review Complainants (Code) (BT-712(a)-LotResult)

* Buyer Review Complainants (Number) (BT-712(b)-LotResult)

* Buyer Review Requests Count (BT-635-LotResult)

* Buyer Review Requests Irregularity Type (BT-636-LotResult)




=== Withheld information about economic operators

This group is selected to be withheld using the code "eop-info" 

Note: For the Organisation Fields included in this group, only those instances that are related to economic operators are withheld. The instances of Organisation Fields related to the Buyer may not be withheld.

* Organisation Name (BT-500-Organization-Company)

* Organisation Identifier (BT-501-Organization-Company)

* Organisation Part Name (BT-16-Organization-Company)

* Organisation Internet Address (BT-505-Organization-Company)

* Organisation eDelivery Gateway (BT-509-Organization-Company)

* Organisation City (BT-513-Organization-Company)

* Organisation Post Code (BT-512-Organization-Company)

* Organisation Country Code (BT-514-Organization-Company)

* Street (BT-510(a)-Organization-Company)

* Streetline 1 (BT-510(b)-Organization-Company)

* Streetline 2 (BT-510(c)-Organization-Company)

* Organisation Natural Person (BT-633-Organization)

* Winner Listed (BT-746-Organization)

* UBO Name (BT-500-UBO)

* City (BT-513-UBO)

* Post Code (BT-512-UBO)

* Country Code (BT-514-UBO)

* UBO Email Address (BT-506-UBO)

* UBO Telephone Number (BT-503-UBO)

* UBO Contact Fax (BT-739-UBO)

* Country Subdivision (BT-507-UBO)

* Street (BT-510(a)-UBO)

* Streetline 1 (BT-510(b)-UBO)

* Streetline 2 (BT-510(c)-UBO)

* Winner Owner Nationality (BT-706-UBO)

* First Name (OPT-160-UBO)

* Tendering Party Name (OPT-211-Tenderer)
